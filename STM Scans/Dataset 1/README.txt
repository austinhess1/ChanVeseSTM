This is the dataset that is used to generate the results shown in figures 2 and 3 of the associated publication.
The sample material used was titanium diselenide (TiSe2)
Only the parent mtrx file and the Z_mtrx files may be present in the target folder.
In the "Results" folder there is the extended output of the script for this dataset.
The number at the beginning of each image's file name is the order in which they were scanned.
Images ending with "L" are the leveled STM scan. Images ending with "I" are the initial level set for the scan.
Images ending with "M" are the masks produced by the Chan-Vese model. Images ending with "O" are the masks produced by Otsu's method.
